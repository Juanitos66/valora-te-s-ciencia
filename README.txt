VALÓRATE CON S-CIENCIA — RADAR S-CIENCIA 2.0
Prototipo PWA educativo para concurso.

Archivos:
- index.html: aplicación completa.
- manifest.json: configuración PWA.
- sw.js: funcionamiento básico offline.
- icon.svg: icono.

Uso:
1) Descomprime.
2) Abre index.html para una demostración local.
3) Para instalación PWA y funcionamiento offline completo, publícala en un servidor HTTPS.
4) No presentes los registros locales ni datos ficticios como resultados reales.

Incluye:
- Menú profesional.
- Datos INEGI MOCIBA 2024.
- Radar ISAC de 36 reactivos, 6 dimensiones.
- Pretest/Postest con código anónimo.
- Cálculo educativo de puntaje.
- Registro local y comparación de promedios.
- Modo demostración para jueces.
- Acciones de autocuidado y red de apoyo.
- Avisos de privacidad y límites del instrumento.

IMPORTANTE:
El instrumento es educativo, no clínico. Antes de investigación real se requiere validación por expertos, piloto, consentimiento/asentimiento conforme al contexto institucional, protección de datos, protocolo de atención y revisión ética/institucional.
