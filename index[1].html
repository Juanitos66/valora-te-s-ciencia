Valórate con S-Ciencia convierte información estadística en reflexión, toma de decisiones, acciones de autocuidado y evaluación del cambio.

¿Qué problema atiende?

La dificultad para reconocer factores que pueden afectar el bienestar y transformar información en decisiones conscientes y acciones preventivas.

¿Qué aporta la 4.0?

Integra datos oficiales, radar educativo, casos de decisión, pretest/postest, base central opcional, panel docente y medición de impacto.

¿Qué NO hace?

No diagnostica depresión, adicciones, obesidad, riesgo suicida ni enfermedades. Un resultado educativo no define a una persona.

Problema, objetivo e innovación

Problema

Los problemas sociales y de bienestar son multifactoriales. La escuela necesita herramientas que ayuden a interpretar evidencia, reconocer factores de atención y fortalecer decisiones sin etiquetar ni diagnosticar.

Objetivo general

Evaluar una estrategia educativa basada en datos estadísticos oficiales, autoconocimiento y toma de decisiones conscientes para fortalecer el autocuidado y el reconocimiento temprano de factores de riesgo en estudiantes de Educación Media Superior.

Innovación

Estadística oficial + reflexión personal + escenarios de decisión + intervención + medición pre/post dentro de un mismo sistema educativo.

1) ¿A quién mide? 2) ¿De qué año es? 3) ¿Qué definición utiliza? 4) ¿Es porcentaje, tasa o número? 5) ¿Qué sí permite concluir? 6) ¿Qué NO permite concluir?

Metodología e intervención

Fase 1 · Diagnóstico: aplicar ISAC pretest y establecer línea base.
Fase 2 · Intervención: seis experiencias educativas centradas en evidencia, reflexión y decisiones.
Fase 3 · Evaluación: aplicar postest.
Fase 4 · Análisis: medias, cambio relativo, pruebas estadísticas y tamaño de efecto cuando corresponda.
Fase 5 · Mejora: documentar resultados, limitaciones y ajustes para la siguiente implementación.

Viabilidad y protección

Técnica

Aplicación web progresiva, compatible con GitHub Pages. Modo local inmediato y conexión central opcional.

Económica

El prototipo puede funcionar con infraestructura de bajo costo. La versión institucional debe evaluar el servicio de base de datos y políticas de seguridad.

Social

Puede aplicarse en grupos y planteles, con acompañamiento docente y rutas de apoyo.

Escalabilidad

Permite comparar grupos y periodos de forma agregada, manteniendo la separación entre datos contextuales y resultados individuales educativos.

Limitaciones

El ISAC requiere validación por expertos y pilotaje. El sistema no debe interpretarse como instrumento clínico.

Protección de datos

Minimizar datos, usar códigos anónimos, acceso docente autenticado, resultados agregados y políticas de retención/borrado.

Configuración técnica

Conexión central

La aplicación funciona en modo local aunque la nube no esté configurada. Para activar la base central, edita config.js con tu URL y clave pública de Supabase y ejecuta el archivo schema.sql en el proyecto de Supabase.

Seguridad: nunca coloques aquí una clave service_role. El frontend debe usar únicamente la clave pública anon y las políticas RLS de la base.

Ruta de instalación

  1. Crear un proyecto en Supabase.
  2. Ejecutar schema.sql en SQL Editor.
  3. Crear el usuario docente en Authentication.
  4. Copiar URL y anon key a config.js.
  5. Subir los archivos a GitHub Pages.
  6. Probar primero con datos ficticios y después con pilotaje autorizado.

Modo jurado · defensa de 3–5 minutos

1. Problema

2. Solución

Radar S-Ciencia: datos oficiales → autoconocimiento → escenarios → acciones → pretest/postest.

3. Evidencia

El sistema está preparado para medir cambio; los resultados reales se obtienen con pilotaje y análisis estadístico.

4. Innovación

Integra ciencia de datos, formación socioemocional y prevención educativa en una experiencia replicable.

5. Viabilidad

6. Impacto

Preguntas difíciles

¿Esto diagnostica? No. Es educativo; no sustituye evaluación clínica.

¿Cómo demostrarán que funciona? Con pretest/postest, validación del instrumento, análisis estadístico y reporte transparente de limitaciones.

¿Qué protege a los estudiantes? Minimización de datos, código anónimo, no solicitar identificadores directos, acceso docente autenticado y resultados agregados.

¿Qué hace diferente al proyecto? No se limita a informar: convierte evidencia en reflexión, decisiones, acciones y medición de cambio.
